HomeworkTracker — Project Docs

Firebase Edition · Criterion C · D.Yedil · S.Khamza

01. Project Description

What is it?

A smart web app for teenagers (10–17) to organise homework, track deadlines, and stay motivated with optional gamification.

Problem

Students forget assignments or rush them last-minute, causing stress and lower grades. HomeworkTracker builds responsibility habits.

Why unique?

Free, no install, adjustable reward system, dark mode, subject filter, search, parental control — all in one file.

Tech Stack

HTML5 + CSS3 + Vanilla JS + Firebase Auth + Firebase Realtime Database. Real-time cloud sync across all devices.
